# 🌱 Field Sprayer Calibration & Tank Mix Calculator

Interactive Shiny application for agricultural sprayer calibration, GPA estimation, and tank mix calculations.

## Features

- Boom width calculation
- GPA calibration
- Travel speed calibration
- Tank mix calculations
- Multi-product support
- Water volume estimation
- Calibration timing tool
- Field application support

## Built With

- R
- Shiny
- bslib
